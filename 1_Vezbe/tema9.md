# Tema 9: Kreiranje i editovanje fajlova

## 1. Otvara ili kreira fajl u editoru nano. (str. 75)
```bash
nano "moj_fajl.txt"
```

## 2. Otvara ili kreira fajl u editoru vim. (str. 75)
```bash
vim "moj_fajl.txt"
```

## 3. Kreira novi prazan fajl ako ne postoji. (str. 76)
```bash
touch "novi_fajl.txt"
```

## 4. Kreira ili prazni fajl bez upisivanja novog reda. (str. 76)
```bash
echo -n > "novi_fajl2.txt"
```

## 5. Pokreće editor nano bez zadatog fajla. (str. 77)
```bash
nano
```

## 6. Pokreće editor vim u terminalu. (str. 78)
```bash
vim
```

## 7. Pokreće tutorijal za editor vim. (str. 78)
```bash
vimtutor
```
