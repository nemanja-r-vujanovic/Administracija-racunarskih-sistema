Lubuntu 26.04 LTS (Resolute Raccoon)

Lubuntu          = lagana Ubuntu distribucija (LXQt grafičko okruženje)
26               = 2026
04               = april
LTS              = dugoročna podrška
Resolute Raccoon = kodno ime verzije

user@user:~$     = prompt
prvi user        = korisničko ime (username)
@                = na             (at)
drugi user       = ime računara   (hostname)

# Pokretanje Python programa:
→ python3 "2_program.py" "tekst"
# python3        = program
# "2_program.py" = argument programa python3
# "tekst"        = argument programa 2_program.py

# Prelazak iz grafičkog korisničkog interfejsa u interfejs virtuelne konzole:
Ctrl + Alt + F4

# Podešavanje većeg fonta u interfejsu virtuelne konzole:
→ sudo dpkg-reconfigure console-setup

# Povratak u grafički korisnički interfejs iz interfejsa virtuelne konzole:
Ctrl + Alt + F7
